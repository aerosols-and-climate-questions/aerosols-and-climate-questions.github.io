# Thanks for contributing!
We appreciate you improving the Aerosols and Climate question bank!
Please take a look at the README and the Wiki if you need help with editing.
This page contains some advice for question writers on best practice when contributing new questinos.

## Roughly one commit per question
You don't have to follow this, of course, and it's not how it always works - you often go to submit and then realise there's a typo so you need another commit! But a good, manageable chunk for a commit is a single complete question. If you're adding multiple questions, editing different questions during different commits makes it easier to revert mistakes or allow some questions but not others. 

## Pull requests (PRs) should ideally focus on questions related to one chapter
It's a lot easier to factually review pull requests focusing on one chapter or topic - much less to read in one chunk! However, this might not always be possible. When you make a PR, if you're writing a brand new question, it's often helpful to point to the part of the book you've read in your PR message.
