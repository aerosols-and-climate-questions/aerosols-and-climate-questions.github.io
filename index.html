Questions on Aerosols and Climate

This site presents a collection of questions on aerosols and their interaction with the climate based largely on the textbook Aerosols and Climate by [Carslaw, K. S., Ed]. Most questions are generic and can be answered without having access to the full textbook, although some of the answers refer to specific sections, equations or figures for further explanation.

This is a work in progress, with new questions being added regularly. We very much welcome feedback and contributions from the community!

Types of Questions

Each page has questions about a different topic in aerosols and their interaction with the climate corresponding to chapters in Aerosols and Climate. There are three types of questions:

  • Review questions test core knowledge and are aimed at scientists who have recently entered the field. It will help to have read the corresponding book chapter, but for most questions it is not necessary.
  • Application questions ask you to apply concepts to everyday questions in aerosol science. These are aimed at students developing understanding of the subject and are approximately at the level of a first-year PhD candidate.
  • Mastery questions require readers to think deeply about the science and apply one or more concepts to a real challenge in research. They are similar to the types of questions that get asked in a PhD viva. Some go beyond the scope of the chapter's contents.

How to contribute

Please get in touch by email if you are interested in contributing questions or providing feedback.

The questions and answers are open-source (with a CC BY 4.0 License) and stored on our Github repository.

We have lots of resources to help you create and submit questions directly through GitHub if this works for you. The project README contains technical details and our project Wiki has detailed practical guides to contribution.

To contribute through GitHub, you can create a pull request and we'll review it. All contributions are acknowledged on our credits page. Alternatively, if you find an error in a question, you can submit an issue on our Github repo to report it.
