About this project

Each page has questions about a different topic in aerosols and their interaction with the climate and corresponds to a chapter in Aerosols and Climate. There are three types of questions:

  • Review questions test core knowledge and are aimed at students who have read the corresponding book chapter.
  • Application questions ask you to apply concepts to everyday questions in aerosol science. These are aimed at students developing understanding of the subject and are approximately at the level of a first-year PhD candidate.
  • Mastery questions require readers to think deeply about the science and apply one or more concepts to a real challenge in research. They are deep and akin to the level of a question asked in a PhD viva. Some go beyond the scope of the chapter's contents.

We welcome contributions from the community! We have lots of resources to help you create and submit questions, including the project README which contains technical details and our project Wiki, which has detailed practical guides to contribution.

To contribute, you can create a pull request and we'll review it. All contributions are acknowledged on our credits page. Alternatively, if you find an error in a question, you can submit an issue on our Github repo to report it.

Please note that while we are in the early stages of development, contributions will only be accepted from those who have been invited to contribute. If you are interested in doing so at this stage, please contact Ken.

The questions on this site are open-source (with a CC BY 4.0 License) and stored on our Github repository.
